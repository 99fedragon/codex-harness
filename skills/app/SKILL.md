# 명령줄 앱

- product/app/main.py 하나로 시작. argparse 로 입력 경로, 출력 경로, 옵션. --help 가 나와야 한다
- 흐름: 읽기 → 검사 (빠진 값, 꼴) → 처리 → 쓰기 → 요약 한 줄 출력 (건수, 걸린 시간)
- 작은 입력으로 먼저 끝까지 돌린다. 그다음 전체
- 검증: product/app/tests/test_main.py 에 작은 입력 파일을 만들어 돌리고 출력 파일의 값을 맞춰 본다. 요구사항마다 시험 하나 (규칙 7)
- 실행 한 줄과 걸린 시간을 보고서.md 실행법에
- 멈추는 조건: 입력이 없거나 꼴이 다르면 메시지를 내고 0 이 아닌 코드로 끝난다
- 데이터는 원본 경로를 읽는다. 복사하지 않는다 (규칙 3)
- 출력 자리는 인자로 받는다 (기본은 실행 폴더 아래). verify 가 자기 폴더로 복사해 돌리고, 외주는 자기 폴더 밖에 쓸 수 없다
