# 모르는 곳 표 (「대화」 를 기록한 뒤 바로)

- 줄에 오르는 것: 담당자가 모른다, 답하기 어렵다, 정한 게 없다, 정해 주세요 라고 한 곳, 답이 README 와 어긋나는 곳, 사람이 따로 물어 안 풀린 것, research 발견 가운데 담당자만 답할 수 있는 것
- 꼴: 한 번에 여섯 줄까지, 범위와 핵심 규칙에 걸리는 것부터. 나머지는 「나머지 N개는 추천대로 둠」

```text
문제 (지금): 종이 장부라 예약이 겹치고 기록을 찾기 어렵다
모르는 곳 3개 (시작 뒤 32분, 합의까지 28분. 추천에 *)
1 대여 일수 칸의 뜻   *A 더 묻기 / B 안 씀
2 같은 날 넘기기      A 더 묻기 / *C 하루 한 사람
3 학기 말 보고        *B 안 함 (새 기능, 30분)
더 물을 글 (1): 「장부에서 그 숫자보다 오래 빌려준 적이 있나요?」
답: 「1 A, 2 C, 3 B」 또는 「추천대로」
```

- A 더 묻기: 좁혀 물을 질문을 쓴다 (다른 부서나 바깥 계약이 걸리나, 따로 필요한 것이 있나, 지금은 어떻게 하나). B 구현 안 함: 소관 밖으로 둔다. C 내 방향: 사람이 정한다. C 가 README 나 대화와 어긋나면 먼저 짚는다
- 추천: A 는 답에 따라 README 의 요구나 규칙의 구현이 달라질 때만. 담당자 말에서 나온 새 기능은 「새 기능, 드는 시간」 을 붙이고 가장 작은 꼴이나 B 를 추천 (담당자의 핵심 문제에 닿는 것만 A 나 C). 구현 쪽이라 모른다고 한 것은 다시 묻지 않고 C (우리가 정함) 와 추천안
- 더 물을 글은 업무 말로 쓴다 (구현 낱말 없이). A 줄을 묶어 한 덩이로, 사람이 그대로 보낼 수 있게
- 열린 줄이 없으면 표 대신 「모르는 곳 없음」 한 줄과 「범위 확인」 제안
- 시간: STATE.md 의 「시작 HH:MM」 과 `./h now` 로 센다. 목표는 시작에서 60분. 45분이면 남은 줄에 추천을 붙여 정리하고 구현 범위 확인 글을 낸다. 접은 줄과 45분에 남은 줄은 「가정 (추천)」 으로만 두고, 사람이 「추천대로」 라고 해야 정해진다
- 답을 받으면: 바뀐 줄만 답으로 보이고 (파일은 만들지 않는다), 요구.md 의 「모르는 곳」 절 (번호 U1 …, 무엇, 지금까지, 고른 것과 결과, 걸리는 요구) 과 결정.md 는 `./h note` 로 서기에 넘긴다. 담당자 말에서 나온 새 기능을 사람이 C (만든다) 로 정하면 메인이 그 자리에서 새 R 번호를 매겨 답에 보이고 h note 에 「R30 반납 기한 알림, 출처 담당자 T2」 꼴로 적는다 (서기가 요구사항 표에 올린다. README 밖 요구는 출처 칸으로 가른다) (번호 U, D 는 메인이 글에 매긴다. B 는 결과 「안 함 (까닭)」 과 깔고 갈 가정 한 줄, C 는 사람의 말 그대로). 표 머리의 「문제 (지금)」 도 같이

# 범위 확인 (「범위 확인」 이나 45분)

- 먼저 사람에게: README 의 요구 (출처가 README 인 R 줄) 가운데 「안 함」 으로 두는 것이 있으면 맨 위에 「README 요구 R5 ⟦내용⟧ 를 안 함으로 둡니다. 괜찮습니까?」 로 묻는다. 담당자 말에서 온 요구 (출처 담당자) 는 「README 에서: R1 ~ R8 / 담당자에서: R30 …」 으로 갈라 보인다 (README 의 핵심이 대화의 요구에 밀리지 않게)
- 담당자에게 보낼 글을 업무 말로 다섯 줄 안팎: 「이렇게 만들겠습니다」 (만들 것), 「이번에는 안 합니다」 (안 만들 것과 까닭), 「이렇게 알고 진행합니다」 (가정), 「이대로 진행해도 될까요?」
- 동의를 「대화」 로 받으면 답에 「합의 확정 (대화 T번호)」 을 보이고 h note 로 서기에 (서기가 합의문 머리를 「확정 HH:MM (대화 T번호)」 으로). 일부만 동의하면 그 줄만 모르는 곳 표로 돌아간다

# 확정 뒤

- 담당자에게 물을 글을 내미는 때: 사람이 분명히 답하기 어려워할 때, 선호의 문제일 때, 선택지가 여럿이고 현업의 쓰임이 가를 때, 구현이나 research 에서 합의문의 가정이 틀린 것이 드러났을 때 (팀장 보고의 「물을 것」 가운데 담당자가 답할 수 있는 것)
- 답이 범위를 바꾸면 바뀐 줄만 보이고 h note 로 서기에 (서기가 합의문의 그 줄에 「바뀜 HH:MM (대화 T번호, 결정 D번호)」), 걸리는 팀장에게 전달문 초안 → 「보낼까요?」
